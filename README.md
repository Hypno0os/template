# 🐾 Animal Communication - Site Web Moderne

Site web moderne pour une communicatrice animale avec des animations fluides et un design responsive.

## ✨ Fonctionnalités

- **Navbar moderne** avec animations et lignes sous les boutons
- **Dégradé animé** en arrière-plan
- **Design responsive** pour mobile et desktop
- **Animations fluides** avec Framer Motion
- **Thème bleu ciel** élégant

## 🚀 Déploiement sur GitHub Pages

### Étape 1: Pousser le code sur GitHub

```bash
# Initialiser le repository (si pas déjà fait)
git init
git add .
git commit -m "Initial commit: Animal Communication website"

# Connecter au repository GitHub
git remote add origin https://github.com/Hypno0os/template.git
git branch -M main
git push -u origin main
```

### Étape 2: Configurer GitHub Pages

1. **Aller sur GitHub** : https://github.com/Hypno0os/template
2. **Cliquer sur "Settings"** (en haut à droite)
3. **Scroller vers "Pages"** (dans le menu de gauche)
4. **Source** : Sélectionner "Deploy from a branch"
5. **Branch** : Sélectionner "main" et "/docs" ou "/ (root)"
6. **Cliquer "Save"**

### Étape 3: Déployer automatiquement

```bash
# Installer gh-pages (si pas déjà fait)
npm install gh-pages --save-dev

# Déployer
npm run deploy
```

### Étape 4: URL du site

Le site sera disponible à : **https://hypno0os.github.io/template/**

## 🛠️ Développement local

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour production
npm run build
```

## 🎨 Technologies utilisées

- **React 18** avec TypeScript
- **Vite** pour le build
- **Tailwind CSS** pour le styling
- **Framer Motion** pour les animations
- **GitHub Pages** pour le déploiement

## 📱 Responsive Design

- **Desktop** : Navigation complète avec animations
- **Mobile** : Menu hamburger animé
- **Tablet** : Adaptation automatique
